# Úvod do Pythonu na Micro:bitu

Výukové materiály ke kurzu programování v Pythonu na micro:bitu.
Série 11 lekcí — od prvního skriptu až po hru dvou hráčů přes rádio.

## Obsah lekcí

| Lekce | Téma | Co se naučíš |
|-------|------|-------------|
| 01 | První program | volání funkcí, `display.show/scroll` |
| 02 | Proměnné | `int`, `str`, sestavování zpráv |
| 03 | Podmínky | `if / elif / else`, tlačítka |
| 04 | Cykly | `while True`, `for`, `sleep()` |
| 05 | Náhoda | `import random`, hod kostkou |
| 06 | Senzory | `float`, `temperature()`, akcelerometr |
| 07 | Seznamy a hudba | listy, indexy, `import music` |
| 08 | Vlastní funkce | `def`, parametry, `return` |
| 09 | Rádio — základy | `import radio`, posílání zpráv |
| 10 | Rádio — hra | reakcní hra + kámen-nůžky-papír pro dva hráče |
| 11 | Volný projekt | vlastní program, vše dohromady |

## Co je v každé složce

Každá složka `lekceXX/` obsahuje:
- `pracovni_list.pdf` — zadání úkolů na hodinu
- `prezentace.pdf` — výklad a příklady (prezentace z hodiny)
- `template.py` *(jen lekce 09 a 11)* — startovní šablona kódu

## Jak začít

1. Stáhni si [Thonny](https://thonny.org/) — vývojové prostředí pro Python
2. Připoj micro:bit přes USB
3. V Thonny zvol interpreter **MicroPython (BBC micro:bit)**
4. Otevři pracovní list a pusť se do úkolů
