\medskip\noindent
Python pracuje se dvěma typy čísel: \pyinline{int} (celá) a \pyinline{float} (desetinná).
Micro:bit nám dává přístup k vestavěnému teploměru a akcelerometru.

% ------------------------------------------------------------------
\begin{ukol}[Teploměr]

Micro:bit zobrazuje aktuální teplotu každé 3 sekundy.

\begin{lstlisting}
from microbit import *

while True:
    temp = temperature()
    display.scroll(str(temp) + "C")
    sleep(3000)
\end{lstlisting}

\hadej{Micro:bit měří teplotu procesoru — ne teplotu vzduchu.
Odhadni: bude číslo vyšší nebo nižší než skutečná teplota v místnosti?
Odhad: \underline{\hspace{4cm}}
\quad Skutečnost: \underline{\hspace{4cm}}}

\begin{enumerate}
  \item Zadej program a spusť ho. Jakou teplotu ukazuje? Odpovídá tvému odhadu?
  \item Co vrací \pyinline{temperature()} — \pyinline{int} nebo \pyinline{float}?
        Jak to snadno zjistíš?
  \item Přidej podmínku: nad 27~°C zobraz \pyinline{Image.HAPPY},
        pod 18~°C zobraz \pyinline{Image.SAD}, jinak \pyinline{Image.MEH}.
  \item Proč nestačí \pyinline{display.show(temp)} bez \pyinline{str()}?
        Zkus to — co se stane?
\end{enumerate}

\odpoved[2.5cm]

\begin{tcolorbox}[colback=code-bg, colframe=gray!40,
                  fonttitle=\small\bfseries, title=Čísla a převody]
  \small
  \begin{itemize}[leftmargin=*]
    \item \pyinline{temperature()} — vrátí teplotu jako \pyinline{int} (stupně Celsia).
    \item \pyinline{str(x)} — převede číslo na řetězec pro zobrazení na displeji.
    \item \pyinline{7 / 2 = 3.5} (float); \pyinline{7 // 2 = 3} (celé); \pyinline{7 \% 2 = 1} (zbytek).
    \item \pyinline{round(x)} — zaokrouhlí; \pyinline{abs(x)} — absolutní hodnota.
  \end{itemize}
\end{tcolorbox}

\end{ukol}

% ------------------------------------------------------------------
\begin{ukol}[Inklinometr — šipky podle náklonu]

Akcelerometr měří náklon micro:bitu.
\pyinline{accelerometer.get_x()} vrátí číslo od~−1024 do~1024.

\begin{lstlisting}
from microbit import *

while True:
    x = accelerometer.get_x()
    if x > 200:
        display.show(Image.ARROW_E)
    elif x < -200:
        display.show(Image.ARROW_W)
    else:
        display.show(Image.DIAMOND_SMALL)
    sleep(100)
\end{lstlisting}

\begin{enumerate}
  \item Zadej program a nakláněj micro:bitem — sleduj, jak se mění šipka.
  \item Změň práh z 200 na 500 — jak se změní citlivost?
  \item Přidej osu Y: \pyinline{accelerometer.get_y()} ovládá šipky nahoru/dolů
        (\pyinline{Image.ARROW_N} a \pyinline{Image.ARROW_S}).
\end{enumerate}

\odpoved[2cm]

\end{ukol}

% ------------------------------------------------------------------
\begin{ukol}[Vlastní senzorový program]

Vytvoř program, který kombinuje alespoň jeden senzor
(\pyinline{temperature()} nebo \pyinline{accelerometer}) s podmínkami a zobrazením.

\medskip
Podmínky:
\begin{itemize}
  \item program musí mít alespoň \textbf{3 různé stavy}
        (např.\ horko\,/\,normál\,/\,zima nebo vlevo\,/\,rovně\,/\,vpravo)
  \item pro zobrazení číselné hodnoty použij \pyinline{str()}
  \item přidej \pyinline{sleep()} pro plynulý chod
\end{itemize}

\odpoved[5cm]

\noindent Výsledný program ulož a připrav k odevzdání do Google Classroom.

\end{ukol}

% ------------------------------------------------------------------
\begin{bonusukol}[Digitální vodováha]

Vodováha indikuje, jestli je plocha vodorovná. Micro:bit zvládne totéž —
kombinuje obě osy akcelerometru a \pyinline{abs()}:

\begin{lstlisting}
from microbit import *

while True:
    x = accelerometer.get_x()
    y = accelerometer.get_y()

    if abs(x) < 150 and abs(y) < 150:
        display.show(Image.YES)      # rovne
    elif abs(x) > abs(y):
        if x > 0:
            display.show(Image.ARROW_E)
        else:
            display.show(Image.ARROW_W)
    else:
        if y > 0:
            display.show(Image.ARROW_S)
        else:
            display.show(Image.ARROW_N)
    sleep(100)
\end{lstlisting}

\begin{enumerate}
  \item Zadej program a polož micro:bit na stůl — zobrazí se \pyinline{Image.YES}?
  \item Proč se porovnávají hodnoty \pyinline{abs(x)} a \pyinline{abs(y)}?
        Co by se stalo bez \pyinline{abs()}?
  \item \textbf{Výzva:} Uprav práh ze 150 na 300 — jak se změní citlivost?
        Jaká hodnota prahu dává nejpřesnější výsledky na tvém stole?
\end{enumerate}

\odpoved[2.5cm]

\end{bonusukol}

% ------------------------------------------------------------------
\begin{bonusukol}[Kompas — 8 světových stran]

Inklinometr z úkolu~2 ukazoval 4 směry. Micro:bit má ale šipky i do diagonál —
\pyinline{Image.ARROW_NE}, \pyinline{ARROW_SE}, \pyinline{ARROW_SW}, \pyinline{ARROW_NW}.

\medskip\noindent
\textbf{Klíčová myšlenka:} nejprve převedeme syrové hodnoty na logické proměnné
(\pyinline{True}/\pyinline{False}), pak je kombinujeme podmínkami.

\begin{lstlisting}
from microbit import *

PRAH = 300   # zkus zmenit a pozoruj citlivost

while True:
    x = accelerometer.get_x()
    y = accelerometer.get_y()

    vpravo = x >  PRAH
    vlevo  = x < -PRAH
    dolu   = y >  PRAH
    nahoru = y < -PRAH

    if vpravo and dolu:
        display.show(Image.ARROW_SE)
    elif vpravo and nahoru:
        display.show(Image.ARROW_NE)
    elif vlevo and dolu:
        display.show(Image.ARROW_SW)
    elif vlevo and nahoru:
        display.show(Image.ARROW_NW)
    elif vpravo:
        display.show(Image.ARROW_E)
    elif vlevo:
        display.show(Image.ARROW_W)
    elif dolu:
        display.show(Image.ARROW_S)
    elif nahoru:
        display.show(Image.ARROW_N)
    else:
        display.show(Image.DIAMOND_SMALL)   # svisly poloh
    sleep(100)
\end{lstlisting}

\begin{enumerate}
  \item Zadej program a otoč micro:bitem do všech 8 stran — zobrazují se správné šipky?
  \item Proč jsou diagonální podmínky (\pyinline{vpravo and dolu} apod.) \textbf{výše}
        než samotné základní směry (\pyinline{elif vpravo})?
        Co by se stalo, kdybys je prohodil?
  \item Změň \pyinline{PRAH} na 150 a pak na 600 — jak se liší chování?
        Jakou hodnotu považuješ za nejpřirozenější?
\end{enumerate}

\odpoved[2.5cm]

\end{bonusukol}
