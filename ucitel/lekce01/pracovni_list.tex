\medskip\noindent
Micro:bit je kapesní počítač s displejem z 25~LED diod. Budeme ho programovat
v~jazyce Python a první věc, co ho naučíme, je představit se světu.

% ------------------------------------------------------------------
\begin{ukol}[Připrav micro:bit]

Micro:bity sdílíme mezi skupinami. Pokaždé, když si vezmeš micro:bit poprvé,
zkontroluj, zda má správný firmware (software, který Pythonu rozumí).

\textbf{Postup:}
\begin{enumerate}
  \item Připoj micro:bit k počítači USB kabelem.
  \item Otevři \textbf{Thonny}.
  \item Otevři nastavení: \textbf{Nástroje → Nastavení → Interpreter}.
  \item Z nabídky vyber \textbf{MicroPython (BBC micro:bit)}.
  \item Klikni na \textbf{Nainstalovat nebo aktualizovat MicroPython} a potvrď instalaci.
  \item Po instalaci klikni \textbf{OK}. V dolním panelu Thonny by se mělo zobrazit:\\
        \texttt{MicroPython v...\ on micro:bit}
\end{enumerate}

\begin{tcolorbox}[colback=yellow!12, colframe=orange!70!black,
                  fonttitle=\small\bfseries, title=Proč to dělám?]
  \small
  Jiná skupina mohla micro:bit použít s jiným softwarem — firmware se prostě
  přepíše. Není to chyba, je to normální. Zabere to asi 10~sekund.
\end{tcolorbox}

\end{ukol}

% ------------------------------------------------------------------
\begin{ukol}[Ahoj, světe!]

Napíšeme první program. V~Thonny klikni do horního (prázdného) okna a zadej:

\begin{lstlisting}
from microbit import *

display.scroll("Ahoj!")
\end{lstlisting}

\hadej{Co se zobrazí na displeji? Jak dlouho text „jede"?
Odhadni, než zmáčkneš F5.}

Spusť program klávesou \textbf{F5} (nebo tlačítkem \textbf{Run} v~nástrojové liště).
Sleduj displej micro:bitu.

\bigskip\noindent
\textbf{Teď to uprav:}
\begin{enumerate}
  \item Změň text \pyinline{"Ahoj!"} na své jméno. Spusť znovu.
  \item Nahraď \pyinline{display.scroll} za \pyinline{display.show} a spusť.
        Co se liší?
\end{enumerate}

\odpoved[2.5cm]

\begin{tcolorbox}[colback=code-bg, colframe=gray!40, fonttitle=\small\bfseries,
                  title=Co dělají tyto příkazy?]
  \small
  \begin{itemize}[leftmargin=*]
    \item \pyinline{display.scroll("text")} — text projede přes displej jako
          běžící nápis (skroluje).
    \item \pyinline{display.show("A")} — zobrazí jeden znak nebo obrázek najednou.
  \end{itemize}
\end{tcolorbox}

\end{ukol}

% ------------------------------------------------------------------
\begin{ukol}[Obrázky]

Micro:bit má sadu připravených obrázků. Zkus:

\begin{lstlisting}
from microbit import *

display.show(Image.HEART)
\end{lstlisting}

Vyzkoušej i další: \pyinline{Image.HAPPY}, \pyinline{Image.SAD},
\pyinline{Image.SURPRISED}, \pyinline{Image.PACMAN}, \pyinline{Image.GHOST}.

\bigskip\noindent
\textbf{Bonus:} Zobraz za sebou dva obrázky s pauzou mezi nimi.
Napoví ti funkce \pyinline{sleep(1000)} — čeká 1000~milisekund (= 1~sekundu).
\textit{(Více o \pyinline{sleep()} v lekci~4.)}

\odpoved[2cm]

\end{ukol}

% ------------------------------------------------------------------
\begin{bonusukol}[Vlastní obrázek]

Micro:bit umí zobrazit obrázek, který si sám nakreslíš.
Každý řádek displeje je 5~číslic (0~=~zhasnuto, 9~=~plný jas):

\begin{lstlisting}
from microbit import *

muj_obrazek = Image("09090:"
                    "90909:"
                    "09090:"
                    "90909:"
                    "09090")

display.show(muj_obrazek)
\end{lstlisting}

\begin{enumerate}
  \item Zadej program — co se zobrazí?
  \item Uprav čísla a vytvoř vlastní vzor: obličej, písmeno, tvar \ldots
  \item \textbf{Výzva:} Udělej dva různé obrázky a zobraz je střídavě se
        \pyinline{sleep(500)} mezi nimi.
\end{enumerate}

\odpoved[2cm]

\end{bonusukol}

% ------------------------------------------------------------------
\begin{ukol}[Připrav program k odevzdání]

Uprav program tak, aby skroloval tvé jméno nebo větu, která tě popisuje.
Ulož soubor (\textbf{Soubor → Uložit jako}) a připrav ho k odevzdání do~Google Classroom:
odevzdáš \textbf{zdrojový kód} nebo \textbf{fotografii / krátké video} micro:bitu při běhu.

\end{ukol}
