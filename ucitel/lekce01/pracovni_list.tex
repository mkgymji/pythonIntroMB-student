\medskip

Micro:bit je malý programovatelný počítač s displejem z 25 LED diod, dvěma tlačítky,
a celou řadou senzorů. Dnes ho poprvé připojíme k počítači a napíšeme první Python program.

% ------------------------------------------------------------------
\begin{ukol}[Připrav micro:bit]

Než budeš moci psát programy, micro:bit potřebuje správný software (firmware).
Protože micro:bity sdílí více skupin, je možné, že na něm firmware chybí nebo je jiný.

\textbf{Postup:}
\begin{enumerate}
  \item Připoj micro:bit k počítači pomocí USB kabelu.
  \item Otevři \textbf{Thonny} (Start → Thonny nebo ikona na ploše).
  \item Zvol \textbf{Nástroje → Nastavení → Interpreter}.
  \item Z rozbalovacího menu vyber \uv{MicroPython (BBC micro:bit)}.
  \item Pokud se v dolním panelu (Shell) zobrazí výzva \texttt{>>>}, firmware je v pořádku.
        Pokud Thonny nabídne instalaci MicroPythonu — klikni \textbf{Instalovat}.
  \item Ověř: po instalaci by se mělo v dolním panelu zobrazit \texttt{MicroPython v...}
\end{enumerate}

\begin{tcolorbox}[colback=yellow!15, colframe=orange!80, title=Poznámka]
  REPL (\texttt{>>>} v dolním panelu) slouží k rychlému vyzkoušení příkazů — jako kalkulačka.
  My budeme psát programy do horního okna a spouštět je celé najednou.
\end{tcolorbox}

\end{ukol}

% ------------------------------------------------------------------
\begin{ukol}[První program]

Napiš program, který na displeji micro:bitu zobrazí tvé jméno nebo pozdrav.

\textbf{Postup:}
\begin{enumerate}
  \item V Thonny klikni do horního (prázdného) okna.
  \item Napiš program:
\end{enumerate}

\begin{lstlisting}
from microbit import *

display.scroll("Ahoj!")
\end{lstlisting}

\begin{enumerate}[resume]
  \item Spusť program zeleným tlačítkem \textbf{Run} nebo klávesou \textbf{F5}.
  \item Sleduj displej micro:bitu.
\end{enumerate}

\medskip
\textbf{Úpravy — zkus sám:}
\begin{itemize}
  \item Změň text v uvozovkách na své jméno.
  \item Místo \pyinline{display.scroll()} zkus \pyinline{display.show()}. Co se liší?
\end{itemize}

\begin{ukol}[Připrav program pro odevzdání]

Uprav program tak, aby scrolloval tvé jméno a za ním větu, která tě popisuje
(škola, věk, koníček — cokoliv).

Výsledný program ulož (\textbf{Soubor → Uložit jako}) a připrav screenshot nebo
fotku/video micro:bitu při běhu — budeš je odevzdávat do Google Classroom.

\end{ukol}

\begin{tcolorbox}[colback=gray!8, colframe=gray!40, title=Doplněk: Thonny doma]
  \small
  Chceš programovat micro:bit i doma? Postup:
  \begin{enumerate}
    \item Stáhni Thonny z \url{https://thonny.org} a nainstaluj.
    \item Spusť Thonny, jdi do \textbf{Nástroje → Spravovat pluginy}, vyhledej
          a nainstaluj \texttt{thonny-microbit}.
    \item Restart Thonny, připoj micro:bit, nastav interpreter
          na \uv{MicroPython (BBC micro:bit)} — stejně jako ve škole.
  \end{enumerate}
\end{tcolorbox}
