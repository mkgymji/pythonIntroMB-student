\begin{ukol}[Skica programu]

Napiš \textbf{pseudokód nebo kostru programu} — hlavní části, ne nutně funkční kód.

\begin{lstlisting}
from microbit import *
# import dalsich modulu...

# definice funkci...

while True:
    # hlavni smycka...
    pass
\end{lstlisting}

\begin{ukol}[Realizace a reflexe]

Po dokončení projektu odpověz:

\begin{enumerate}
  \item Co se ti povedlo? Co jsi musel/a upravit oproti plánu?
  \item Jaký koncept byl nejtěžší? Kde jsi potřeboval/a pomoc?
  \item Co bys přidal/a, kdybys měl/a více času?
\end{enumerate}

\odpoved[4cm]

\noindent Výsledný program ulož a připrav k odevzdání do Google Classroom
spolu s krátkým popisem (2--4 věty).

\end{ukol}

\begin{bonusukol}[Výzvy pro rychlé]

Jsi hotov/a dřív než ostatní? Rozšiř svůj projekt jednou z těchto výzev:

\medskip
\textbf{Výzva A — Rekord (highscore):}\\
Přidej proměnnou, která si pamatuje nejlepší výsledek a ukáže ho po stisku B.
\begin{lstlisting}
rekord = 0
# ...
if skore > rekord:
    rekord = skore
    display.show(Image.HAPPY)
\end{lstlisting}

\medskip
\textbf{Výzva B — Odpočítávání před startem:}\\
Na začátku programu zobraz odpočet 3–2–1 a teprve pak spusť hlavní smyčku.
\begin{lstlisting}
for i in range(3, 0, -1):
    display.show(str(i))
    sleep(700)
display.show(Image.YES)
\end{lstlisting}

\medskip
\textbf{Výzva C — Konfigurace přes tlačítka:}\\
Přidej „nastavovací" obrazovku: tlačítkem A/B nastavíš parametr programu
(rychlost, obtížnost, počet pokusů) a teprve pak program spustíš.

\medskip
\textit{Vyber si jednu výzvu, implementuj ji a krátce popiš, co jsi přidal/a.}

\odpoved[3cm]

\end{bonusukol}
